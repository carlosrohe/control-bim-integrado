El sistema

Cinco capas conectadas, tres niveles de capacidad.

Ciclo de vida del proyecto

El sistema opera de forma continua durante todo el ciclo de vida del proyecto: desde el desarrollo del proyecto ejecutivo, detectando inconsistencias antes de construir, hasta la ejecución en obra, auditando avance real contra modelo y presupuesto cada semana.

Proyecto ejecutivo

Modelo, presupuesto y cronograma se validan antes de romper terreno.

Cimentación

Auditoría cruzada de avance real contra modelo y presupuesto.

Estructura

Alertas de desviación entre programa y presupuesto ejercido.

Acabados y cierre

Trazabilidad completa hasta la última partida ejercida.

Las cinco capas

01
Modelo
Revit + Dynamo — fuente de datos del proyecto
02
Presupuesto
OPUS + SQL LocalDB — control de costo por partida
03
Programación
MS Project — cronograma y avance por jornada
04
Integración
MCP + REST API (Node.js) — conexión entre capas en tiempo real
05
Visualización
Power BI — dashboard de decisión para la dirección

Las cinco capas están activas desde el primer trazo hasta la última partida ejercida — no se instalan una vez, operan todo el proyecto.

Tres niveles de capacidad

Detección

Disponible

Auditoría cruzada continua entre modelo, presupuesto y avance (2+ fuentes), con corrección.

Alerta por impacto

Disponible

Semáforo que cruza avance físico real contra programa y contra presupuesto ejercido, con alertas específicas por partida. Habla directo al director de proyecto, no solo al BIM manager.

Anticipación

En desarrollo

Proyección de tendencia sobre las series de avance, antes de que la desviación ya ocurrida se refleje en el semáforo. En desarrollo — hoja de ruta visible, no se ofrece todavía como servicio activo.

Para quién es esto

Es para quienes quieren mejorar cómo gestionan la información de sus proyectos.

✓

Tienes proyectos activos y quieres mejorar tu proceso y sistema de gestión de información.

✓

Tu equipo de gestión es de 3 a 10 personas — director, gerente de proyecto, residente, administrador.

✓

Usas OPUS, Neodata, MS Project, o cualquier sistema que exporte a Excel.

✓

No cuentas con un equipo BIM interno con capacidades equivalentes.

✓

La visibilidad del avance real es crítica para tu operación.

✓

Tienes un proceso donde la información se retrasa o se rechaza entre quien la genera y quien la valida — sea un cliente, una dirección, o una entidad reguladora.
